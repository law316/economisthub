# AfriEcon Nexus

A premium Vite + React + TypeScript frontend for a collaborative economics network connecting economists, students, researchers, institutions and policy communities across Africa and globally.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

Import the GitHub repository into Vercel. The included `vercel.json` supports client-side routing.

## Backend integration

Current content is typed mock data. Replace mock data access with API calls when the backend is ready. The UI is intentionally componentized so authentication, WebSocket chat, live-session providers, research-room storage and notification APIs can be connected later.
